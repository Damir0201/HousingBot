# 🏠 DOMIK CRM — Telegram-бот и CRM для агентства недвижимости

Автоматизированная система подбора долгосрочной аренды, записи на просмотры, управления объектами и работы с клиентами в Telegram + REST API.

## ✨ Основные возможности

- **🤖 ИИ-ассистент (OpenAI / Groq / OpenRouter)** — ведёт диалог на естественном языке, вызывает инструменты поиска квартир (`search_properties`), сохраняет предпочтения клиента в CRM (`save_client_preferences`), отвечает по базе знаний (`search_faq`) и передаёт сложные запросы оператору (`handoff_to_operator`). При недоступности LLM автоматически переключается на кнопочное меню.
- **🔍 Пошаговый подбор жилья** — фильтрация по району, бюджету, комнатности и сроку аренды, карточки с альбомами фотографий (до 10 фото).
- **📅 Бронирование просмотров (3+ агентов)** — автоматический расчёт слотов с буфером между встречами, защита от пересечений на уровне PostgreSQL (`EXCLUDE USING gist`), лист ожидания (`waitlist`), напоминания за 15 минут, продление при опоздании (`+15 мин`), перенос и отмена.
- **🔄 Автоматизация статусов объектов** — при переводе объекта в `rented` / `reserved` / `archived` все будущие просмотры автоматически отменяются, а клиентам отправляется уведомление с подборкой похожих свободных квартир.
- **📊 Двусторонняя синхронизация с Excel (`.xlsx`)** — выгрузка и загрузка базы объектов через Telegram (`/staff`) или по расписанию (Celery Beat) с разрешением конфликтов (`updated_at`) и добавлением фотографий прямо из чата Telegram.
- **🌍 Мультиязычность** — русский (`ru`), английский (`en`), итальянский (`it`).

## 🚀 Быстрый старт для команды (через Docker)

### 1. Склонируйте репозиторий и создайте `.env`

```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd HousingBot
cp .env.example .env
```

### 2. Заполните обязательные поля в `.env`

Откройте `.env` и укажите:

```env
# Токен Telegram-бота от @BotFather
BOT_TOKEN=1234567890:AAF...

# Telegram ID владельцев/администраторов через запятую (узнать свой ID можно у @userinfobot)
OWNER_IDS=111111111,222222222

# ИИ-ассистент (необязательно: без ключа бот работает в кнопочном режиме)
# Пример для бесплатного Groq API (https://console.groq.com/keys):
LLM_BASE_URL=https://api.groq.com/openai/v1
LLM_API_KEY=gsk_ваш_ключ
LLM_MODEL=qwen/qwen3.8-27b
```

### 3. Запустите все сервисы

```bash
docker compose up -d --build
```

Docker Compose автоматически:
1. Поднимет **PostgreSQL 16** и **Redis 7**.
2. Выполнит миграции БД (`migrate` → `alembic upgrade head`).
3. Запустит Telegram-бота (`bot`), REST API (`api` на http://localhost:8000/docs), фоновые воркеры (`worker`) и планировщик (`beat`).

## 🛠 Как протестировать функции после запуска

1. **Клиентский режим**:
   - Напишите боту `/start`, выберите язык.
   - Напишите запрос своими словами (например: *«Ищу 2-комнатную квартиру в Центре до 1500 евро»*) или нажмите **🔍 Подбор жилья**.
2. **Панель сотрудника / владельца (`/staff` или кнопка `🛠 CRM`)**:
   - **📥 Выгрузить Excel** — скачайте шаблон таблицы объектов `.xlsx`.
   - **📤 Загрузить Excel** — заполните строки с квартирами и отправьте файл боту.
   - **🏠 Объекты** — выберите квартиру, чтобы сменить её статус (`Свободен` / `Бронь` / `Сдан` / `Архив`) или прикрепить фотографии кнопкой **📷 Добавить фото**.
   - **🧑‍💼 Агенты** — добавьте агента по показам командой `/add_agent <telegram_id> [Имя]` (предварительно агент должен нажать `/start` в боте).
   - **📅 Расписание** и **🎫 Обращения** — управление просмотрами и тикетами клиентов.
3. **Swagger UI (REST API)**:
   - Доступен по адресу: http://localhost:8000/docs (авторизация по заголовку `X-API-Key` из `.env`).
